# Session log: 2026-10-04

## Incident: every live run failed for ~10 hours (fixed)
- **What:** all 67 runs between 2026-10-03 20:23 and 2026-10-04 06:33 UTC failed with `SyntaxError: f-string: unmatched '('` in
  `main.py`.
- **Cause:** the AskNews/Gemini split commit (2026-10-03 ~20:13 UTC) put double quotes inside a double-quoted f-string. That is valid on
  Python 3.12 (the PC, where the dry runs passed) but not on 3.11 (GitHub Actions). The offline tests never import `main.py`, so CI's
  test run on 3.11 didn't catch it.
- **Impact:** no tournament questions missed (no FutureEval, MiniBench or Cup questions opened in that window); the 00:00 and 05:00 UTC
  wide runs were lost (~4 main-site questions and the Toman retry).
- **Fix:** the f-string is rewritten; a new test compiles `main.py`, `bot_helpers.py` and `tools/*.py`, and CI runs it on 3.11. A manual
  run at 06:45 UTC succeeded.
- **Lesson:** a dry run on the PC isn't enough for changes to `main.py`: wait for the CI test run (Python 3.11) before relying on a push.
